# LETONICE SPOLEČNĚ

Veřejný web: https://teezee551-hub.github.io/letonice-spolecne/

Statický web; GitHub Pages publikuje kořen větve main. Soubor .nojekyll vypíná Jekyll. Veškeré odkazy na soubory jsou relativní a fungují pod cestou /letonice-spolecne/.

Obsah a fotografie vycházejí z dodaných podkladů. Mapa používá Leaflet 1.9.4 a OpenStreetMap; licence je přiložena v assets/vendor/leaflet/LICENSE. Koupaliště rozlišuje archivní fotografii, návrh Jana Ježorka (2026) a studii DIMENSE (2021). Kontaktní formulář není zapojen dle přání zadavatele.

Pro lokální náhled spusťte v tomto adresáři statický HTTP server. Aktualizace souborů ve větvi main automaticky spustí GitHub Pages.
